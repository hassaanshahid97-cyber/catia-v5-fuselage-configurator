WHAT ARE THE PARAMETERS?
================================================================================

The code has 4 main parameters you can modify:

Location: Form1.vb, Lines 13-16

Parameter 1: CYLINDER_RADIUS = 25.0
  • Controls the cylinder diameter
  • Default: 25 millimeters
  • Change to: Any value > 0
  • Example: 50.0 for larger cylinder

Parameter 2: CYLINDER_HEIGHT = 100.0
  • Controls the cylinder height/length
  • Default: 100 millimeters
  • Change to: Any value > 0
  • Example: 200.0 for taller cylinder

Parameter 3: CYLINDER_AXIS = "Z"
  • Controls which direction cylinder extends
  • Options: "X", "Y", or "Z"
  • Default: "Z" (vertical)
  • Change to: "X" or "Y" for different orientation

Parameter 4: PARAMETRIC = True
  • Enables parametric design mode
  • Default: True (enabled)
  • Change to: False to disable
  • Keep at True for flexibility

All parameters are clearly marked and easy to find!

================================================================================
HOW TO CUSTOMIZE
================================================================================

To change the cylinder size:

BEFORE:
  Private Const CYLINDER_RADIUS As Double = 25.0
  Private Const CYLINDER_HEIGHT As Double = 100.0

AFTER (Example: Larger cylinder):
  Private Const CYLINDER_RADIUS As Double = 50.0
  Private Const CYLINDER_HEIGHT As Double = 200.0

Then rebuild (F6) and run again (F5) - new cylinder created with new size!

See QUICK_REFERENCE.txt for more examples.
