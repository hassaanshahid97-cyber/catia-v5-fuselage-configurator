┌─ CALCULATIONS ────────────────────────────────────────────────────────────┐
│                                                                             │
│ For Default Parameters: R=25mm, H=100mm                                   │
│                                                                             │
│ Surface Area    = 2π(25)² + 2π(25)(100)                                 │
│                 = 19,634.95 mm²                                           │
│                                                                             │
│ Volume          = π(25)²(100)                                            │
│                 = 196,349.54 mm³                                          │
│                                                                             │
│ Lateral Area    = 2π(25)(100)                                            │
│                 = 15,707.96 mm²                                           │
│                                                                             │
│ Generic Formulas:                                                          │
│ ────────────────                                                           │
│ Surface Area    = 2πr² + 2πrh                                            │
│ Volume          = πr²h                                                   │
│ Lateral Area    = 2πrh                                                   │
│                                                                             │

┌─ VALIDATION RULES ────────────────────────────────────────────────────────┐
│                                                                             │
│ RADIUS         Must be > 0                                               │
│                Recommended: 5 to 500 mm                                  │
│                                                                             │
│ HEIGHT         Must be > 0                                               │
│                Recommended: 5 to 1000 mm                                │
│                                                                             │
│ AXIS           Must be "X", "Y", or "Z"                                 │
│                (case-insensitive)                                        │
│                                                                             │
│ RATIO          Height/Radius should be reasonable                       │
│                Too large = tall, thin cylinder                          │
│                Too small = flat disc                                     │
│                Ideal: Between 1 and 10                                   │

┌─ GENERATION PROCESS (Sequential) ─────────────────────────────────────────┐
│                                                                             │
│ 1. Click Button1                                                          │
│ 2. CATIA application initializes (or opens if closed)                   │
│ 3. New part document is created                                          │
│ 4. XY plane is referenced from body origin                              │
│ 5. Sketch is created on the plane                                       │
│ 6. Circle is drawn with specified radius                                │
│ 7. Constraints are applied (center, radius)                            │
│ 8. Sketch is closed and finalized                                       │
│ 9. Pad feature is created (extrusion)                                   │
│ 10. Height constraint is applied                                         │
│ 11. 3D geometry is generated and rendered                               │
│ 12. Document is saved                                                    │
│ 13. Success message displays                                             │
│ 14. Ready for further modifications                                      │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
