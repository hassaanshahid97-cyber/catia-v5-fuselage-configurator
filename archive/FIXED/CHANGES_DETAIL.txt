TECHNICAL NOTES
================================================================================

1. WHY System.Reflection.Missing.Value?
   -------
   In .NET COM interop, when a COM method has optional parameters:
   - VBScript/VBA: passing Nothing or omitting param works fine
   - .NET: passing Nothing = null pointer, which COM rejects
   - Solution: use System.Reflection.Missing.Value for optional parameters

   CATIA's AddSectionToLoft signature:
   Function AddSectionToLoft(section As Reference, orientation As Integer,
                             closingPoint As Optional) As Any

   The third parameter (closingPoint) defines an optional coupling/closing
   curve. When not used, CATIA expects Missing.Value, not null.


2. SCOPE:
   -------
   This fix applies specifically to:
   - CATIA V5 R21 COM interface
   - .NET late binding (Option Strict Off)
   - Any AddSectionToLoft calls passing optional parameters


3. NO BREAKING CHANGES:
   -------
   - Backward compatible with existing error handling
   - Try/Catch blocks unchanged
   - Logging output unchanged
   - Geometry output identical (same algorithm)

================================================================================
KNOWN ISSUES (NOT INTRODUCED BY THIS FIX)
================================================================================

CloseSurface May Fail:
- Some CATIA V5 installations cannot execute CloseSurface via COM
- If you see: "[!] CloseSurface skipped - surfaces created but not closed"
- SOLUTION: Manually close the surfaces in CATIA UI:
  1. Open CATIA (part should be loaded)
  2. Select the Join surface (e.g., "Fuselage_Shell")
  3. Insert > Surface-Based Features > Close Surface
  4. Repeat for each longeron Join if needed

This is NOT a code error—it's a CATIA environment issue, not caused by
this fix.
